documented gap between the current implementation and SPEC.md.

design decisions live in the cited spec sections, not here.

completed work leaves this file rather than accumulating in it — the
release history in CHANGELOG.md is the record. `/compose:roadmap`
refills it from the next SPEC.md gap.
